# Lightweight Dependency Injection Container

Учебная реализация небольшого DI-контейнера на Java. Проект показывает, как с помощью Reflection API, аннотаций и XML-конфигурации можно создавать объекты и автоматически связывать их зависимости без использования Spring Framework.

## Возможности

- создание объектов по описанию из `config.xml`;
- установка простых значений полей из XML-конфигурации;
- связывание объектов через ссылки на другие компоненты;
- автоматическое внедрение зависимостей по аннотации `@Auto`;
- поиск реализации не только по точному классу, но и по совместимому типу через `isAssignableFrom`;
- поддержка внедрения объектов-наследников и реализаций интерфейсов;
- диагностический вывод процесса создания и внедрения объектов.

## Как это работает

1. Контейнер читает XML-конфигурацию с описанием компонентов.
2. Через Reflection API создаёт экземпляры указанных классов.
3. Заполняет настроенные свойства простыми значениями или ссылками на другие компоненты.
4. Находит поля, отмеченные аннотацией `@Auto`.
5. Подбирает совместимую зависимость и внедряет её в объект.
6. Возвращает полностью собранный объект из контекста.

## Демонстрационная модель

В проекте используется простая предметная область автомобиля:

- `Car` — объект, которому требуются зависимости;
- `Engine` — двигатель;
- `Gear` и его реализация `Manual` — коробка передач;
- `Context` — контейнер, отвечающий за создание и связывание объектов;
- `@Auto` — пользовательская аннотация для автоматического внедрения.

Это позволяет на небольшом примере увидеть основные принципы IoC и Dependency Injection.

## Технологии

- Java 8+
- Reflection API
- пользовательские аннотации
- XML-конфигурация
- принципы IoC и Dependency Injection

## Запуск

1. Откройте проект в IntelliJ IDEA или другой Java IDE.
2. Укажите JDK 8 или новее.
3. Проверьте настройки компонентов в `config.xml`.
4. Запустите демонстрационный класс `Main2`.

В консоли будет показан процесс автоматического создания объектов и внедрения зависимостей.

## Учебная ценность

Проект помогает понять, что происходит внутри DI-фреймворков:

- как контейнер создаёт объекты;
- как связываются зависимости;
- зачем нужны аннотации;
- как Reflection API позволяет анализировать классы во время выполнения;
- как совместимость типов помогает отделить интерфейс от конкретной реализации.

## Статус

Учебный проект для практики Java Reflection и самостоятельной реализации базовых механизмов dependency injection.
